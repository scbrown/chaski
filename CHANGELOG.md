# Changelog

## 0.1.0

- Installable Python wheel and source distribution with the `chaski` command.
- Event and schedule reactions, durable verdict/outbox delivery, change-driven
  adapters, graph and JSONL receivers, and configured Alertmanager routing.
- An isolated event verification command with negative, delivery, reader and
  replay controls for installer verification.
- Versioned release artifacts, contributor instructions and documentation book.
